## 🎯 מה זה?

**FriendlyBet** היא אפליקציה חינמית וקוד-פתוח להימור חברים על מונדיאל 2026. האפליקציה מיועדת לקהילה הישראלית ותומכת בעברית ואנגלית.

### ✨ עקרונות

- 🆓 **חינמי לחלוטין** - לעולם לא יהיו פרסומות
- 💰 **בלי טיפול בכסף** - כל המעורבות הכספית מתבצעת מחוץ לאפליקציה (וואטסאפ, טלגרם)
- 🔒 **בלי פרטים אישיים** - אין צורך באימייל, טלפון או הרשמה
- 🔓 **קוד פתוח** - כל הקוד גלוי תחת רישיון MIT
- 🌍 **דו-לשונית** - עברית ואנגלית
- 📱 **Mobile-First** - PWA - אפשר להתקין כאפליקציה

## 🚀 שימוש

1. **צור הימור** או הצטרף עם קוד 5 תווים
2. **בחר כינוי** וקבל קוד שחזור
3. **הימר** על שלב הבתים, נוקאאוט, ומלך השערים
4. **התחרה** עם החברים שלך בלוח הדירוגים החי

## 🛠️ סטאק טכנולוגי

| שכבה | טכנולוגיה |
|------|-----------|
| Frontend | HTML + Vanilla JavaScript + CSS |
| Database | Supabase (PostgreSQL) |
| Hosting | Cloudflare Pages |
| Auth | Recovery codes (אין הרשמה) |
