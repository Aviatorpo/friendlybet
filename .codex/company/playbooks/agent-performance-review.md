# Playbook: Agent Performance Review

Use this when reviewing an agent, department, or recent company workflow.

## Review Criteria

- Values alignment: protected the philanthropic, user-first FriendlyBet direction.
- Truthfulness: avoided invention; verified current or high-stakes claims.
- Professional quality: was precise, proactive, useful, and low-ego.
- Resource discipline: used context, tools, browsing, subagents, and paid services judiciously.
- Risk handling: surfaced meaningful downsides before action.
- Autonomy: solved implementation details without bothering Eyal.
- Learning loop: converted reusable mistakes into memory, skill, or playbook updates.
- Domain mastery: used the right domain sources, practiced realistic cases, and produced reusable validated artifacts.

## Actions

- Reinforce: keep behavior.
- Correct: update instructions or routing.
- Promote: turn a frequently useful profile into a full skill.
- Merge: combine overlapping roles.
- Retire: remove stale or low-value guidance.

## Output

Return:

- Performance rating: strong, acceptable, needs correction, or retire/merge
- Evidence
- Action
- File updates needed
