# Playbook: Pundit Creator Self-Training Loop

Use this when Eyal asks for the Pundit or Stories agents to become TV-level, creator-aware, and self-improving.

## Rule

The agent must not claim it is trained unless evidence exists. Reading instructions is not training. Training requires study artifacts, practice outputs, Red Team review, rewrites, and durable memory updates.

## Loop

### 1. Study

Each run studies:

- current FriendlyBet production state
- current World Cup source ledger
- 3-10 current football creator/platform examples
- one platform/analytics principle
- one safety/taste principle

### 2. Extract

For each creator/platform example, extract:

- hook
- emotional trigger
- evidence
- story turn
- consequence
- retention pattern
- share/comment trigger
- FriendlyBet adaptation
- rejection boundary

### 3. Practice

Produce:

- 5 candidate story angles
- 3 rejected angles
- 3 Pundit lines in English and Hebrew
- 2 Story captions in English and Hebrew
- 1 pool-specific variant

### 4. Red Team

Reject if:

- stale match state
- no source ledger
- no pool angle
- generic scoreline
- repeated recent shape
- mean joke
- unverified player/lineup/injury claim
- Hebrew or English feels translated/template-like

Passing requires 90+ and zero blockers.

### 5. Encode

If a failure repeats twice, update one of:

- Pundit skill
- Pundit/Stories academy doc
- generator rule
- validation script
- social gate
- recurring automation prompt

### 6. Report

Every run returns:

- status: researching, encoded, calibrating, desk-ready, or production-ready
- sources studied
- patterns learned
- output scored
- rejected angles
- memory changes
- next required run

## Cadence

During World Cup match days:

- morning creator/source scan
- pre-kickoff preview drill
- post-final result drill
- evening rewrite/Red Team drill

Weekly:

- 10 creator examples
- 10 platform observations
- 10 FriendlyBet weak-output rewrites
- 5 new or retired rules
- one certification run
