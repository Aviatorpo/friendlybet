# Playbook: Operating Cadences

Use this to choose the right company process for recurring work.

## Cadences

### Full Company Planning Review

Use before presenting a meaningful plan, roadmap, implementation strategy, recovery path, operating process, or broad ambiguous recommendation to Eyal. The CEO should consider every department, involve the relevant senior reviewers, synthesize disagreements, revise the plan, and recheck affected departments before presenting one recommendation.

Output: goal, active departments, not-applicable departments, resolved disagreements, final plan, validation plan, cost/resource note, risks, needs Eyal.

### Feature Kickoff

Use for a new product feature. Include Product, Engineering, Design, QA, Privacy, and FinOps as needed.

Output: MVP, risks, owner, next step.

### SEO Or Growth Sprint

Use for discovery or public positioning. Include Growth, Content, Product, Engineering, Privacy, and QA.

Output: diagnosis, prioritized backlog, implementation batch, measurement plan.

### Release Review

Use before shipping app code, scoring changes, migrations, or public copy. Include QA, Engineering, Product, Privacy, and Release Manager.

Output: ready/block decision, tests, version status, remaining risk.

### Postmortem

Use after mistakes, incidents, regressions, hallucinations, bad routing, or wasteful work. Include HR, affected departments, and Enablement.

Output: incident, root cause, lesson, memory update.

### Strategy Review

Use for direction, multi-sport expansion, monetization philosophy, or major tradeoffs. Include CEO, Executive, Product, FinOps, Privacy, and relevant domain teams.

Output: strategic decision, assumptions, risks, next bet.

### Agent Performance Review

Use when agent quality needs review or periodically after several major tasks. Include HR and the CEO.

Output: reinforce, correct, update, promote, or retire.

### Agent Domain Mastery Training

Use when Eyal asks to raise agent expertise, deepen department knowledge, or make agents better at their worlds of content. Include CEO, HR, Executive, FinOps Enablement, and the target departments.

Output: training objective, department tracks, practice cases, validated artifacts, memory updates, next training batch.
