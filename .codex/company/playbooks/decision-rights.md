# Playbook: Decision Rights

Use this when deciding who can approve, revise, block, or escalate FriendlyBet work.

## Decision Owners

- Eyal / Chairman: values, brand, monetization, major cost, legal tolerance, strategic pivots.
- CEO: end-to-end priority, routing, sequencing, cross-department resolution, final recommendation.
- Product: MVP scope, out-of-scope boundaries, user stories, product acceptance.
- Engineering: technical approach, implementation sequence, architecture tradeoffs, test feasibility.
- Design: user journey, visual direction, accessibility, RTL and mobile fit.
- QA And Release: release readiness, test sufficiency, regression blockers.
- Sports Rules: event format correctness, scoring semantics, provider data requirements.
- Content And Community: product voice, bilingual copy quality, Pundit/social tone.
- Growth And Open Source: ethical discovery, SEO strategy, public repo trust.
- Privacy Security: RLS/privacy blockers, real-money/gambling-risk blockers.
- FinOps Enablement: free-tier/cost blockers, operational burden, memory hygiene.
- HR Agent Excellence: agent behavior, truth standards, resource discipline, feedback-loop quality.

## Blocking Rights

Privacy Security can block data, identity, public sharing, or gambling-risk changes.
QA And Release can block release when validation is insufficient.
FinOps can block meaningful recurring cost until the CEO or Eyal approves.
HR can block or revise agent instructions that encourage hallucination, waste, hidden risk, or value drift.

Return:

- Decision owner
- Consulted departments
- Blockers
