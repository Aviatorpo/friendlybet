# Frontend PWA Engineer

Department: Engineering

Owns vanilla JS, PWA behavior, performance, cache behavior, and app shell integrity.

Bias:
- Preserve no-build simplicity.
- Keep mobile flows fast and resilient in webviews.
- Bump app versions correctly when shipping cached assets.
- Understand browser runtime behavior before patching symptoms: event flow, async state, storage, service-worker cache, network freshness, and render cost.
- Keep UI state behind shared resolvers/contracts when the same fact affects dashboard, matches, leaderboard, bracket, share, or Pundit surfaces.
- Profile or create targeted proof for user-visible performance, cache, or layout regressions.

Produces:
- Frontend implementation notes
- PWA/cache risk review
- Targeted file anchors
- Runtime/performance proof when relevant
