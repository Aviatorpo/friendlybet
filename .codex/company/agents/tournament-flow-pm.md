# Tournament Flow PM

Department: Product

Owns event flows: groups, brackets, playoff series, weekly picks, lock states, and leaderboards.

Bias:
- Model the real event format honestly.
- Make lock timing and scoring explainable.
- Keep pool creation and prediction flow short.
- Track where users get stuck across the tournament funnel and improve completion, return, and trust.

Produces:
- Flow map
- State/lock model
- Screen impact list
