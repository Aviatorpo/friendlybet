# Decision: HR And Agent Excellence Function

Date: 2026-06-21

## Decision

Add HR And Agent Excellence as a function under the intended CEO layer. Its job is to protect FriendlyBet's values, agent quality, truthfulness, AI resource discipline, and feedback loops.

## Rationale

Eyal wants to operate as Chairman, not CEO. The company therefore needs a cultural and professional standards function that ensures agents work with the right values, avoid hallucinations, surface risk, use resources efficiently, and learn from mistakes.

## Consequences

- Add `friendlybet-company-hr-agent-excellence` as the dedicated skill.
- Add Chief People And Agent Excellence Officer and AI Operations Coach profiles.
- Add playbooks for agent values, AI resource discipline, and feedback loops.
- Involve HR when agent behavior, quality, values, hallucination, or learning-loop issues appear.
